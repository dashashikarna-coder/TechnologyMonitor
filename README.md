## Строгий отбор

Правила — в `config/filters.yaml`: тендер попадает в тему, только если ключевое слово есть в названии;
работы и услуги (строительство, монтаж, обслуживание, обучение, эфир…) отсекаются; патент — слово в названии
или минимум 2 разных слова темы в реферате. После правки перезапустите сбор — база переразметится.

## Обновление

Автоматически раз в 3 дня в 10:00 (Планировщик заданий Windows, задача «TechnologyMonitor - обновление тендеров
и патентов»; если компьютер был выключен — при включении). Журнал — `data/update.log`.
Вручную: двойной щелчок по `update.bat`.
